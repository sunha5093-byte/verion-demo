# 베리온 외부 시연 배포본

배포 대상: **이 public-demo 폴더의 내용만**.
시작 파일: **index.html**. 첫 접속은 고객 홈페이지입니다.

포함 파일: index.html, base.css, public.css, customer-menu.css, customer-menu.js, public.js, demo.js, 이 안내 파일.
서버 실행·빌드·설치·환경변수·API 키가 필요 없는 정적 사이트입니다.
정적 호스팅에서 배포/출력 디렉터리를 public-demo로 지정하거나 이 폴더 내용만 업로드하세요. 프로젝트 루트 전체를 올리지 마세요.
SPA 재작성 설정 없이 #public / #consult / #apply 해시 경로로 이동합니다.

상단의 테스트 안내는 항상 표시합니다. 가상 정보 채우기 버튼으로 체험할 수 있습니다.
상담·가입 제출은 완료 화면만 체험합니다. 실제 서버·관리자·이메일·문자 등에 전송하지 않습니다.
입력값과 연락처는 localStorage에 저장하지 않습니다. 가상 폼 임시 값은 메모리에서만 유지하고 완료 시 제거합니다.
localStorage에는 verion-public-demo-experience-v1 키의 version/completedCount 값만 보관합니다. 원본 관리자의 저장 키는 읽거나 수정하지 않습니다.
관리자 로그인·회원/상담/매칭/검증/만남 관리 코드와 데이터는 포함하지 않습니다.
보안정책 메타 태그로 네트워크 연결(connect-src)과 폼 전송(form-action)을 차단합니다. 호스팅 사업자 자체의 일반 접속 로그까지 제어하는 것은 아닙니다.

공개 HTTPS 주소가 생성된 후 그 주소를 카카오톡으로 공유하면 됩니다. 현재 폴더 준비만 완료했으며 공개 업로드는 하지 않았습니다.
공유 미리보기용 제목/설명을 포함하고 검색 수집은 noindex,nofollow로 요청합니다. 호스팅·메신저의 캐시에 따라 미리보기 반영은 달라질 수 있습니다.

사업자번호·신고번호·실제 주소·가격 등 미확정 정보를 만들지 않았습니다. 실제 고객 접수용으로 사용하지 마세요.

상단 6개 메뉴는 PC에서 호버/클릭으로 열고, 모바일에서는 햄버거 버튼과 아코디언으로 사용합니다. 30개 하위 링크는 기존 섹션·신청 폼·별도 시연 안내로 연결됩니다. 이야기/공지와 개인정보 처리방침·이용약관은 준비 중인 시연용 안내이며 허구의 후기나 확정 정책을 만들지 않았습니다.

히어로 배경영상: verion-hero.mp4, hero-video.css, hero-video.js를 함께 배포하세요. 모든 경로는 상대경로입니다. 무음 자동 반복재생 및 모바일 인라인 재생을 적용하며, 재생 실패/자동재생 제한에서는 기존 정적 배경을 유지합니다. 영상 일시정지 버튼을 제공합니다.

영상 재생 수정: preload=auto, 초기화 즉시 muted=true 후 play() 요청, 실패 시 콘솔 오류와 정적 fallback. 영상/오버레이/본문은 z-index 0/1/2로 분리하며 기본 영상은 opacity:1입니다. 이전 캐시 방지를 위해 영상 CSS/JS와 public.js에 버전 쿼리를 적용했습니다. public-demo 폴더 내용 전체로 기존 배포를 교체하세요.

첫 화면 개편: 아이보리 배경에서 설명 54 / 영상 46의 2단 구성을 사용합니다. 영상은 오른쪽 아치형 프레임 안에서만 재생하며, 모바일은 설명·신청 버튼·310px 영상 순입니다. 영상 속성과 실패 시 정적 프레임 fallback은 유지합니다. 이전 전체 배경영상 설명보다 이 구성이 우선합니다.
